👋 Focus Gate is installed

Every new tab now asks what you're here for. Two things to do right now so there's no back door:

  1. Open chrome://extensions → Focus Gate → Details → turn on Allow in Incognito.
  2. Pin the extension (puzzle icon → pin) so the timer is always visible.

Settings

Dashboard
🔒 Settings are locked while a focus session runs. They unlock when it ends — that's on purpose.

AI gatekeeper (optional)

When on, Claude checks the sites you ask for and your searches against the goal you typed. Without it, the extension uses a waiting timer instead. You need an Anthropic API key (console.anthropic.com). It is stored only in this browser and sent only to api.anthropic.com. Each check is a small request, billed to your key.

💚 ADHD manager

Kind check-ins while you work, soft nudges when you drift, and a water break reminder when you've been hyperfocused for a long time. Click any notification to jump back to your gate.

Brain dump side panel: Alt+B on any page (change it at chrome://extensions/shortcuts).
